# SenRate

Pass rate & consistency tracker for Geometry Dash (Geode mod) by **Sen**.

- Every run you do (25-60, 27-100...) in a **Runs** tab and on the level complete screen.
- 100%s from every start pos, pass rate, streaks and estimated chance of a full run.
- Per-part analysis that separates practice from long runs (detects your real worst part and chokes).
- Tips and a practice plan, death histogram, All-time / Session / Recent views.
- Noclip support: every hit ends a run and starts a new one.
- Gray X deletes the session, red X deletes the level's whole history.
- English & Español.

## Install

Download `sen.senrate.geode` from the [Releases](../../releases) page and copy it into
`Geometry Dash/geode/mods`.

## Build

Requires the [Geode SDK](https://docs.geode-sdk.org) and CLI:

```
geode build
```
